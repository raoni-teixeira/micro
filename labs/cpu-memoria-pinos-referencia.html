O que é um SFR

Um registrador de função especial (SFR, Special Function Register) é uma posição da memória de dados que não guarda uma variável sua: ela está ligada a um circuito do chip. Escrever num SFR liga um pino, dispara uma conversão ou configura um temporizador; ler um SFR devolve o estado de um pino ou o resultado de uma medida. Para o processador, é uma posição de memória como qualquer outra — a mesma instrução que grava uma variável grava um SFR. p. 68, §5.3.5

No PIC18F4550 os SFRs ocupam 0xF60–0xFFF, no topo do banco 15. Endereços sem registrador leem 0. A lista completa, com o endereço de cada um, é a Tabela 5-1; os bits de cada registrador e o valor depois do reset estão na Tabela 5-2. p. 68, Tabela 5-1 p. 69–72, Tabela 5-2

Como uma instrução alcança um endereço de 12 bits

O endereço de dados tem 12 bits, mas a instrução carrega só 8 (o campo f). Os 4 que faltam vêm de um de dois lugares, escolhido pelo bit a da instrução:

Bit aEndereço efetivoUsoOnde está
1BSR<3:0> : fQualquer banco; exige MOVLB antesp. 65, §5.3.2
0Access bank: f < 0x60 → 0x0f; f ≥ 0x60 → 0xFfRAM baixa e todos os SFRs, sem tocar no BSRp. 67, §5.3.3

Como todos os SFRs do 4550 estão em 0xF60–0xFFF, todos cabem no access bank: ler ou escrever qualquer SFR custa uma instrução, sem trocar de banco. p. 66, Figura 5-5

Do pino ao endereço O pino 19 é RD0 (p. 2). Ele é o bit 0 da porta D. Para pôr 1 nele, escreve-se 1 no bit 0 de LATD, que está em 0xF8C (p. 68). Como 0xF8C ≥ 0xF60, o access bank o alcança com f = 0x8C e a = 0: a instrução é BSF 0x8C, 0, 0. Em C, as três formas abaixo geram essa mesma instrução. 

LATDbits.LATD0 = 1;                          // nome do xc.h
LATD |= 0x01;                                // o registrador inteiro
(*(volatile unsigned char *)0xF8C) |= 0x01;  // o endereço cru
