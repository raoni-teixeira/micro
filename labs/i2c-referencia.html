A ideia: dois fios, endereço no próprio barramento

O I²C usa só dois fios, compartilhados por todos os dispositivos: SDA (dado) e SCL (relógio, gerado pelo mestre). Não há fio de seleção: o primeiro byte de cada transação carrega o endereço do dispositivo, e só ele responde.

As linhas são de dreno aberto: os dispositivos só sabem puxar para 0. O nível 1 vem de resistores de pull-up. Por isso a descida é rápida e a subida é lenta, uma carga RC:

tsubida (de 30 % a 70 % de VDD) ≈ 0,85 · Rpull-up · Cbarramento     (limite a 100 kHz: 1000 ns)

Cada byte ocupa 9 pulsos de relógio: 8 de dado, mais significativo primeiro, e 1 de reconhecimento, em que quem recebe puxa SDA para 0 (ACK) ou deixa em 1 (NACK).

tempo de um byte = 9 / fSCL     (100 kHz → 90 µs por byte)

Regra de ouro NACK depois do endereço quer dizer "ninguém respondeu": endereço errado, memória desligada da linha, ou a memória ocupada no ciclo interno de escrita. O barramento não diferencia os três casos.

No PIC18F4550, o módulo MSSP usa RB0 = SDA e RB1 = SCL, os mesmos pinos dos botões INT0 e INT1. Com o I²C ligado, não aperte os botões. Os dois pinos são configurados como entrada (TRIS = 1): o módulo assume o controle.

A memória 24Cxx

Byte de controle, o primeiro de toda transação:

b7b6b5b4b3b2b1b0
1010A2A1A0R/W0 = escrita

1010 identifica a família de memórias. A2 A1 A0 são os pinos de endereço do chip (no kit, todos em 0), o que dá 0xA0 para escrita e 0xA1 para leitura. Nas versões maiores, parte desses bits vira número do bloco de 256 bytes.

A leitura começa como uma escrita: o mestre escreve o endereço interno, e com a partida repetida inverte o sentido sem soltar o barramento. Escrita e leitura são fases de uma mesma transação.

O ciclo interno de escrita

A parada (P) de uma escrita dispara a gravação dentro da memória, que leva até 5 ms. Durante esse tempo a memória não responde: qualquer transação recebe NACK no byte de controle.

escrita de N bytes, um a um: N · (3 · 9 / fSCL + tWR)
escrita de N bytes por página (página P): ⌈N / P⌉ · ((2 + P) · 9 / fSCL + tWR)

exemplo, 8 bytes a 100 kHz: um a um ≈ 8 · 5,27 ms = 42,2 ms; por página ≈ 0,9 ms + 5 ms = 5,9 ms

Como esperar o fim da gravaçãoCusto
Espera fixa de 5 mssempre o pior caso
Consulta por ACK: repetir S · 0xA0 até a memória responder ACKespera só o necessário; a memória avisa quando terminou

Dentro da página, o endereço dá a volta: gravar além do fim da página sobrescreve o início dela, sem aviso. Alinhe os blocos grandes ao começo da página.

Código recomendado (R11)

#define MEM 0xA0u                  /* 1010 000 0: família, chip 000, escrita */

void i2c_iniciar(void)
{
    TRISBbits.TRISB0 = 1; TRISBbits.TRISB1 = 1;   /* o módulo assume SDA e SCL */
    SSPSTAT = 0x80;                /* SMP = 1: 100 kHz              */
    SSPADD  = 39;                  /* 16 MHz / (4 x 100 kHz) - 1    */
    SSPCON1 = 0x28;                /* SSPEN = 1, mestre I2C         */
    SSPCON2 = 0x00;
}
static void i2c_ocioso(void) { while ((SSPCON2 & 0x1F) || (SSPSTAT & 0x04)) { } }
void i2c_start(void)   { i2c_ocioso(); SSPCON2bits.SEN  = 1; while (SSPCON2bits.SEN)  { } }
void i2c_restart(void) { i2c_ocioso(); SSPCON2bits.RSEN = 1; while (SSPCON2bits.RSEN) { } }
void i2c_stop(void)    { i2c_ocioso(); SSPCON2bits.PEN  = 1; while (SSPCON2bits.PEN)  { } }
uint8_t i2c_escrever(uint8_t b)    /* devolve 1 se houve ACK */
{
    i2c_ocioso(); SSPBUF = b;
    while (SSPSTAT & 0x01) { }     /* BF: espera o byte sair */
    i2c_ocioso();
    return (uint8_t)!SSPCON2bits.ACKSTAT;
}

/* escreve k bytes numa página e espera o ciclo interno por consulta de ACK */
void mem_pagina(uint8_t end, const uint8_t *d, uint8_t k)
{
    i2c_start(); i2c_escrever(MEM); i2c_escrever(end);
    for (uint8_t i = 0; i < k; i++) i2c_escrever(d[i]);
    i2c_stop();                    /* aqui começa o ciclo interno */
    for (;;) {                     /* consulta por ACK */
        i2c_start();
        if (i2c_escrever(MEM)) break;   /* ACK: a gravação terminou */
        i2c_stop();                     /* NACK: ainda gravando     */
    }
    i2c_stop();
}

A máscara 0x1F em SSPCON2 pega os 5 bits de comando (ACKEN a SEN); 0x04 em SSPSTAT é o bit R/W, ligado enquanto um byte é transmitido. O módulo está ocioso quando todos são 0.

A memória interna do PIC18F4550

O chip tem 256 bytes de EEPROM de dados, acessados por registradores, sem barramento. Uma posição nunca gravada lê 0xFF.

EEPGD0 = dadosCFGS0 = dados—FREEWRERRWRENpermite escritaWRinicia escritaRDinicia leitura
 
uint8_t eeprom_ler(uint8_t end)
{
    EEADR = end;
    EECON1bits.EEPGD = 0; EECON1bits.CFGS = 0;
    EECON1bits.RD = 1;
    return EEDATA;
}
void eeprom_escrever(uint8_t end, uint8_t dado)
{
    EEADR = end; EEDATA = dado;
    EECON1bits.EEPGD = 0; EECON1bits.CFGS = 0;
    EECON1bits.WREN = 1;
    uint8_t salvo = INTCONbits.GIE;
    INTCONbits.GIE = 0;            /* a sequência não pode ser interrompida */
    EECON2 = 0x55;                 /* a "fechadura": 0x55, 0xAA, WR       */
    EECON2 = 0xAA;
    EECON1bits.WR = 1;
    INTCONbits.GIE = salvo;
    while (EECON1bits.WR) { }      /* cerca de 4 ms */
    EECON1bits.WREN = 0;
}

Grave quando o valor parou de mudar, ou quando a energia vai faltar: nunca a cada volta do laço. Um marcador gravado por último (R11) distingue um dado válido de uma memória apagada ou de uma gravação interrompida.
