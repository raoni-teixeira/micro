A ideia: um registrador que conta sozinho

Um temporizador é um registrador que incrementa a cada pulso de uma fonte de contagem, sem executar instrução. Ao passar do valor máximo, ele volta a zero e levanta um indicador (um bit, TMRxIF). O indicador não se apaga sozinho: o programa precisa zerá-lo.

O contador não sabe o que é tempo. A diferença entre temporizador e contador está só na fonte dos pulsos:

Só Timer0, Timer1 e Timer3 contam pulsos de um pino. O Timer2 só conhece o relógio interno: ele serve para gerar tempo (e o PWM), nunca para contar eventos.

  • Fonte interna: um pulso por ciclo de instrução, FOSC/4. A 16 MHz, isso dá um pulso a cada TCY = 250 ns. Contar pulsos, nesse caso, é medir tempo.
  • Fonte externa: um pino. Cada borda válida vale um incremento. Contar pulsos, nesse caso, é contar eventos, como voltas de um eixo ou peças numa esteira.

Contador de 8 bits e de 16 bits

O tamanho do contador define quantos pulsos cabem antes do estouro:

TamanhoFaixaPulsos até estourarEstouro sem divisor, a 250 ns
8 bits0x00 … 0xFF25664 µs
16 bits0x0000 … 0xFFFF65 53616,384 ms

Um contador de 16 bits ocupa dois registradores de 8 bits: TMRxL (byte baixo) e TMRxH (byte alto). Quando TMRxL passa de 0xFF para 0x00, ele manda um vai-um para TMRxH. O indicador só sobe quando os dois bytes passam juntos de 0xFFFF para 0x0000.

No modo de 8 bits do Timer0 (T08BIT = 1), só TMR0L conta, e o estouro de 0xFF para 0x00 já levanta TMR0IF.

O byte alto é um buffer, não o contador

O processador lê e escreve um byte por vez, mas o contador pode mudar entre uma operação e outra. Para evitar isso, TMR0H (e TMR1H/TMR3H com RD16 = 1) não é o byte alto real. É uma cópia intermediária, trocada com o contador no instante em que se acessa o byte baixo:

OperaçãoOrdem obrigatóriaPor quê
Escrever 16 bitsTMR0H primeiro, depois TMR0LA escrita em TMR0L transfere os 16 bits de uma vez
Ler 16 bitsTMR0L primeiro, depois TMR0HA leitura de TMR0L congela o byte alto no buffer

A ordem invertida não gera erro de compilação. O contador parte de um valor que ninguém pediu, e o erro muda de uma execução para outra.

// escrita: alto no buffer, baixo transfere
TMR0H = (uint8_t)(PRECARGA >> 8);
TMR0L = (uint8_t)(PRECARGA & 0xFF);

// leitura: baixo congela o alto
uint8_t  lo = TMR0L;
uint16_t n  = ((uint16_t)TMR0H << 8) | lo;

Timer0: o caminho do pulso

Cada bit de T0CON controla uma chave no caminho entre a fonte de pulsos e o contador:

Cada seletor é um bit: o valor em vermelho indica qual entrada passa. Ler da esquerda para a direita é ler T0CON do bit 5 ao bit 0.

Após o reset, T0CON = 0xFF: o Timer0 já está ligado, em 8 bits, contando o pino RA4. O bootloader pode ter mudado isso. Escreva sempre o registrador inteiro, nunca bit a bit a partir de um valor que você não conhece.

Pré-carga: escolher o intervalo

Sem pré-carga, o contador percorre sempre a faixa inteira. Para um intervalo menor, ele começa de um valor mais alto e estoura antes. O divisor escolhe o tamanho do passo; a pré-carga escolhe onde a contagem começa. O divisor alonga o intervalo, a pré-carga encurta.

N = intervalo / (TCY · divisor)   (precisa ser ≤ 2n)
pré-carga = 2n − N   (n = 8 ou 16)

Receita: escolha o menor divisor que faça N caber em 2n, porque o passo menor dá o ajuste mais fino. Depois calcule a pré-carga e escreva o valor de novo a cada estouro, porque depois do estouro o contador recomeça de zero.

A escrita em TMR0 inibe o incremento por 2 TCY e zera a contagem parcial do divisor. A recarga sempre atrasa um pouco. Por isso a recarga é feita logo após o estouro, e não quando o laço principal tiver tempo.

Contando pulsos externos

Para trocar a fonte, basta mudar um bit, T0CS ou TMR1CS. O resto do temporizador (tamanho, divisor, estouro, indicador) funciona igual. O que muda é o que um incremento significa.

Timer0 pelo pino RA4/T0CKI

  1. Pino como entrada: TRISAbits.TRISA4 = 1. RA4 não é canal analógico no PIC18F4550, então ADCON1 não interfere.
  2. T0CS = 1 (fonte externa).
  3. Escolha a borda com T0SE. Com botão e resistor de pull-up (solto = 1), a borda de subida acontece ao soltar.
  4. PSA = 1 para contar todo pulso, ou PSA = 0 e T0PS para contar um a cada 2, 4, …, 256.
  5. Zere TMR0 e leia quando quiser. Em 8 bits, o valor lido é o número de pulsos, módulo 256.

No kit, RC0 recebe o tacômetro do cooler (ponto SPEED, chave CH3-2) e também a chave SW2. Com o Timer1 contando por um tempo conhecido, a leitura dá pulsos por segundo, ou seja, a rotação. Confira na bancada quantos pulsos o cooler dá por volta.

Timer1 pelo pino RC0/T13CKI

  1. Pino como entrada: TRISCbits.TRISC0 = 1.
  2. TMR1CS = 1 (fonte externa) e T1OSCEN = 0 (sem cristal; o sinal entra direto em T13CKI).
  3. Borda fixa: só subida. Depois de ligar o Timer1, a primeira subida só conta se houver antes uma descida.
  4. T1SYNC = 0 sincroniza o pulso com o relógio interno. É o modo recomendado para ler o valor com o programa rodando.
  5. RD16 = 1 para ler os 16 bits pelo buffer, como no Timer0.
Parâmetro do pulso em T0CKI (sem divisor)MínimoA 16 MHz
Tempo em nível alto e em nível baixo0,5 TCY + 20 ns145 ns
PeríodoTCY + 10 ns260 ns (≈ 3,8 MHz)

Com o divisor atribuído, o pino aceita pulsos mais rápidos, porque o divisor fica antes do sincronismo. Botões e tacômetros estão muitas ordens de grandeza abaixo desse limite. O problema deles é outro: o repique. O contador conta cada fechamento e abertura do contato, e dez apertos raramente dão dez.

Igual ao Timer1, com duas diferenças. A fonte externa (TMR3CS = 1) é o mesmo pino T13CKI ou o oscilador do Timer1. E os bits T3CCP2:T3CCP1 escolhem qual temporizador serve de base para os módulos de captura e comparação: 00 = Timer1 para os dois CCP; 01 = Timer3 para CCP2 e Timer1 para CCP1; 1x = Timer3 para os dois.

Timer2 — 8 bits com período programável

O Timer2 não estoura em 0xFF. Ele conta de 0 até o valor de PR2 e, no pulso seguinte, volta a zero sozinho. Por isso ele não precisa de pré-carga: o período fica em PR2 e se repete sem intervenção do programa. Cada volta a zero passa por um pós-divisor, e só a cada 1 … 16 voltas o TMR2IF sobe.

T2CON — controle do Timer2

b7b6b5b4b3b2b1b0
— T2OUTPS3:0pós-divisor: valor + 1 TMR2ONliga T2CKPS1:0divisor

Valor após reset: -000 0000. PR2 após reset: 0xFF.

  • T2CKPS1:0: 00 = 1:1, 01 = 1:4, 1x = 1:16.
  • T2OUTPS3:0: 0000 = 1:1, 0001 = 1:2, …, 1111 = 1:16.
  • Escrever em TMR2 ou em T2CON zera as contagens parciais do divisor e do pós-divisor.

Tvolta = (PR2 + 1) · TCY · divisor
TTMR2IF = Tvolta · pós-divisor
máximo: 256 · 250 ns · 16 · 16 = 16,384 ms

No PWM, o período é Tvolta (o pós-divisor não participa) e a resolução é log2(4 · (PR2 + 1)) bits. Com PR2 = 255 e divisor 1:16 (T2CON = 0x06), o período é 1024 µs (976,6 Hz) com 10 bits de resolução.

O Timer2 é compartilhado por CCP1 e CCP2 no modo PWM: as duas saídas têm, obrigatoriamente, a mesma frequência.

Indicadores e habilitações

O indicador sobe no estouro mesmo que a interrupção esteja desligada. Isso permite consultar o bit no laço principal. O bit só volta a 0 quando o programa o zera. Um estouro que acontece com o bit ainda em 1 se perde, porque um bit não conta até dois.

Timer1PIR1bits.TMR1IF (bit 0)PIE1bits.TMR1IE (bit 0)TMR1IE = 1, PEIE = 1, GIE = 1
Timer2PIR1bits.TMR2IF (bit 1)PIE1bits.TMR2IE (bit 1)TMR2IE = 1, PEIE = 1, GIE = 1
Timer3PIR2bits.TMR3IF (bit 1)PIE2bits.TMR3IE (bit 1)TMR3IE = 1, PEIE = 1, GIE = 1

O Timer0 fica em INTCON, junto das habilitações gerais. Os outros são periféricos e precisam também de PEIE (INTCON bit 6). Esquecer esse bit é o motivo mais comum de "a interrupção do Timer1 nunca acontece".

Código de referência

Intervalo fixo com Timer0, consultando o indicador

#define PRECARGA  25536u              // 65536 - 40000: 10 ms a 250 ns

static void t0_recarregar(void)
{
    TMR0H = (uint8_t)(PRECARGA >> 8);    // alto vai para o buffer
    TMR0L = (uint8_t)(PRECARGA & 0xFF);  // esta escrita transfere os dois
}

void t0_iniciar(void)
{
    t0_recarregar();
    T0CON = 0x88;                 // ligado, 16 bits, interno, sem divisor
    INTCONbits.TMR0IF = 0;
}

// no laco principal:
if (INTCONbits.TMR0IF) {          // passaram 10 ms?
    INTCONbits.TMR0IF = 0;        // o hardware nao zera
    t0_recarregar();
    /* ... */
}

Rotação do cooler: Timer1 conta, Timer0 marca 1 s

#define PRECARGA_1S  49911u           // 1 s com divisor 1:256

TRISCbits.TRISC0 = 1;             // RC0 = T13CKI (SPEED): entrada
TMR1H = 0; TMR1L = 0;
T1CON = 0x83;                     // RD16, 1:1, sem oscilador, sincronizado, externo, ligado

TMR0H = (uint8_t)(PRECARGA_1S >> 8);
TMR0L = (uint8_t)(PRECARGA_1S & 0xFF);
T0CON = 0x87;                     // ligado, 16 bits, interno, 1:256
INTCONbits.TMR0IF = 0;

for (;;) {
    if (INTCONbits.TMR0IF) {      // fechou a janela de 1 s
        INTCONbits.TMR0IF = 0;
        TMR0H = (uint8_t)(PRECARGA_1S >> 8);
        TMR0L = (uint8_t)(PRECARGA_1S & 0xFF);

        uint8_t  lo = TMR1L;      // baixo primeiro: congela o alto
        uint16_t pulsos = ((uint16_t)TMR1H << 8) | lo;
        TMR1H = 0; TMR1L = 0;     // nova janela

        /* pulsos por segundo; rpm = pulsos * 60 / pulsos_por_volta */
    }
}
