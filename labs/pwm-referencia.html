PWM e estágio de potência (PIC18F4550) — Folha de Referência

Timer2 dá o período, CCP1 dá a largura, a carga escolhe a frequência e a chave entrega a corrente

Microcontroladores — DENE/UFMTConsulta permitida

Por que PWM: o pino só decide

O pino entrega 5 V e no máximo 25 mA (limite absoluto por pino). O 18F4550 não tem conversor digital-analógico, e mesmo que tivesse, um transistor em série esquentaria tanto quanto a carga. A saída é ligar e desligar uma chave depressa e deixar a carga fazer a média.

A chave quase não dissipa porque ou está aberta (sem corrente) ou fechada (sem tensão). O CVREF não é DAC: é uma escada de 16 degraus, de alta impedância, para o comparador.

A ideia: o Timer2 dá o ritmo, o CCP1 decide a largura

O TMR2 sobe em rampa de 0 até PR2 e volta a 0: isso fixa o período. O CCP1 compara a rampa com um valor de 10 bits (CCPR1L:DC1B): o pino fica alto do início do período até a rampa alcançar esse valor, e baixo daí até o fim. Isso fixa a largura. O pré-divisor só muda a velocidade da rampa.

A razão escrita no meio do segundo período só vale no terceiro: o hardware a copia para CCPR1H no casamento TMR2 = PR2. Trocar a razão a qualquer momento nunca gera pulso truncado.

FPWM = FOSC / (4 · pré · (PR2 + 1))
talto = D · TOSC · pré     (D = valor de 10 bits, CCPR1L:DC1B)
razão cíclica = D / (4 · (PR2 + 1))
resolução = log2(4 · (PR2 + 1)) bits

Regra de ouro A razão cíclica não é D/1024. O denominador é 4 · (PR2 + 1), que só vale 1024 com PR2 = 255. Mudar PR2 para subir a frequência muda a escala de todo valor de razão.

A 16 MHz: TOSC = 62,5 ns e TCY = 250 ns. O "+1" vem de serem PR2 + 1 contagens: a última leva o TMR2 de PR2 de volta a 0. A razão conta em TOSC, não em TCY: daí o fator 4 e os 2 bits extras.

Conta resolvida: exemplo A (PR2 = 255, pré 1:16)

  • Frequência e resolução brigam. Diminuir PR2 sobe a frequência e corta passos de razão.
  • CCP1 e CCP2 dividem o mesmo Timer2. Não há como ter um a 1 kHz e o outro a 25 kHz ao mesmo tempo.
  • O pós-divisor não muda o PWM. Ele só espaça o TMR2IF.

Registradores

Quatro bastam: PR2 (período), T2CON (pré-divisor e liga), CCP1CON (modo e 2 bits baixos da razão) e CCPR1L (8 bits altos da razão).

CCP1CON — modo e os 2 bits baixos da razão

  • CCPR1L: os 8 bits altos de D. Escrito a qualquer momento, só vale no próximo período.
  • PR2: o fim do período, 8 bits.
  • CCP2CON é igual, sem os bits 7–6. A saída do CCP2 é RC1 com CCP2MX = ON (padrão) ou RB3 com OFF.
  • ECCP1AS (desligamento automático) e ECCP1DEL (tempo morto) ficam no valor de reset.

#define PR2_LED        255u
#define T2CON_LED      0x06u    /* pós 1:1, TMR2ON, pré 1:16 → 976,6 Hz */
#define PR2_VENT       159u
#define T2CON_VENT     0x04u    /* pós 1:1, TMR2ON, pré 1:1  → 25 kHz   */

static void pwm1_razao(uint16_t d)
{
    CCPR1L = (uint8_t)(d >> 2);              /* 8 bits altos */
    CCP1CONbits.DC1B = (uint8_t)(d & 0x03u); /* 2 bits baixos */
}

static void pwm1_iniciar(uint8_t periodo, uint8_t t2con)
{
    LATCbits.LATC2   = 0;       /* LAT antes de TRIS */
    TRISCbits.TRISC2 = 1;       /* pino desligado enquanto configura */
    PR2 = periodo;
    CCP1CON = 0x0C;             /* antes da razão: zera DC1B */
    pwm1_razao(0);
    PIR1bits.TMR2IF = 0;
    T2CON = t2con;
    while (!PIR1bits.TMR2IF) {  /* um período inteiro passou */
    }
    TRISCbits.TRISC2 = 0;       /* só agora o pino entrega o PWM */
}

/* Exemplo A: o potenciômetro (10 bits) entra direto na razão (1024 passos) */
pwm1_iniciar(PR2_LED, T2CON_LED);
pwm1_razao(adc_ler());

/* Exemplo B: 640 passos; 1023 · 5 / 8 = 639 */
pwm1_iniciar(PR2_VENT, T2CON_VENT);
pwm1_razao((uint16_t)((adc_ler() * 5u) >> 3));

Os passos 1 e 7 são o "LAT antes de TRIS": o pino só vira saída quando o que ele vai mostrar já está decidido. Em hardware, o mesmo papel é do resistor de pull-down na porta do MOSFET, que segura a carga desligada durante reset e bootloader.

PWM por software: janela de tempo com o Timer0

#define JANELA_MARCAS 100u           /* 100 · 10 ms = 1 s; 2000 = 20 s */
#define PRECARGA      25536u         /* 0x63C0: 40 000 · 250 ns = 10 ms */
#define AQUECEDOR_BIT 0x20u          /* RC5: o XC8 não define LATCbits.LATC5 no 18F4550 */

static volatile uint16_t marcas_ligado = 0; /* o laço escreve, o tratamento lê */

void __interrupt() tratar(void)
{
    static uint16_t marca = 0;
    if (INTCONbits.TMR0IF) {
        INTCONbits.TMR0IF = 0;
        TMR0H = (uint8_t)(PRECARGA >> 8);   /* alto primeiro */
        TMR0L = (uint8_t)(PRECARGA & 0xFF);
        if (++marca >= JANELA_MARCAS) {
            marca = 0;                       /* nova janela */
        }
        if (marca < marcas_ligado) {
            LATC |= AQUECEDOR_BIT;           /* parte ligada da janela */
        } else {
            LATC &= (uint8_t)~AQUECEDOR_BIT;
        }
    }
}

/* no laço principal; 32 bits porque 1023 · 2000 não cabe em 16 */
uint16_t m = (uint16_t)(((uint32_t)adc_ler() * JANELA_MARCAS) >> 10);
INTCONbits.GIE = 0;                  /* seção crítica: 16 bits, duas escritas */
marcas_ligado = m;
INTCONbits.GIE = 1;

É o "controle por janela de tempo" dos controladores de temperatura industriais. Pré-carga e T0CON são os mesmos do R6; a seção crítica é a do R7.
